MXM is expected to expose multiple operator interaction surfaces.

These include:

- CLI workflows,
- TUI workflows,
- remote web operations surfaces,
- scheduled reports and alerts,
- future programmable agent interfaces.

The web operations surface is intended to provide secure remote observability and
operational interaction with the running Money Machine.

The public publishing website, documentation system, and private operations plane are
treated as distinct surfaces with different security and operational requirements.
